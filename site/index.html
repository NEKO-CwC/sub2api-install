大约 2 分钟

把 AI 编程工具接到 Sub2API

选好工具和系统，复制一条命令到终端运行。脚本会自动写好配置、校验 Key，最后发一条测试消息。Key 只在你的终端里输入，不经过浏览器。

1

打开终端

终端是一个用文字和电脑对话的窗口。后面那条命令就粘贴在这里。第一次用的话，按下面三步做即可。

  1. 按 Win + X，在弹出的菜单里选 「终端」 或 「Windows PowerShell」。
    如果菜单里没有，点开始菜单搜索 PowerShell。
  2. 窗口打开后会显示一行以 PS C:\Users\你的用户名> 结尾的提示符。光标停在 > 后面，说明可以输入了。
  3. 不用右键粘贴：直接 Ctrl + V 就能粘贴，然后按 Enter 执行。
  1. 按 Command + 空格 打开聚焦搜索，输入 终端 或 Terminal，按 Enter。
  2. 也可以从 访达 → 应用程序 → 实用工具 → 终端 打开。
  3. 窗口里出现以 % 或 $ 结尾的提示符，就可以粘贴命令了（Command + V）。
  1. 按 Ctrl + Alt + T，大多数桌面发行版会直接打开终端。
  2. 如果没反应，在应用菜单里找 Terminal / 终端 / Console。
  3. 提示符通常以 $ 结尾。粘贴用 Ctrl + Shift + V。

3

准备一个 Key

Key 相当于你的通行证。脚本运行时会让你粘贴，不会保存在网页里。

  • 打开 sub2api.ncuos.com/keys，登录你的账号。
  • 点「创建 API Key」，给它起个名字（比如 我的笔记本），选好分组。
  • 复制以 sk- 开头的那一串。先放在剪贴板里，下一步会用到。
Key 等同于密码。不要发到群里、不要提交到 Git 仓库、不要贴进截图。泄露了就在 Keys 页面删掉重建。
